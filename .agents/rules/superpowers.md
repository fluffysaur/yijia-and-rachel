# Superpowers Engineering Discipline

1. **Brainstorming Before Creative Work**:
   - Before implementing net-new features, visual styling changes, or layout redesigns, explore requirements and present bounded multi-choice options (A/B/C) to the user.
   - Do NOT write code until the user approves the approach.

2. **Test-Driven Development (TDD)**:
   - For bug fixes and logic changes, write a failing automated test first to reproduce the issue, implement the fix, and verify it passes.

3. **Systematic Debugging**:
   - When encountering a failure or unexpected behavior, inspect the root cause before proposing or making edits. Never guess or apply arbitrary changes.

4. **Verification Before Completion**:
   - Always run the relevant test suite and production build before declaring work complete.
